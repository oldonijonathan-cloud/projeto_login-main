# Projeto Login

Página de login responsiva feita no curso da [Refatorando](https://plataforma.refatorando.com/).

## O que tem

- Layout em duas colunas (imagem de boas-vindas + formulário), que vira uma coluna no celular
- Campos com label, tipo `email` e validação nativa do navegador (`required`)
- Botão de login com Google e link de cadastro
- Animação suave na imagem de fundo (desligada para quem prefere menos movimento)

## Como abrir

Abra o `index.html` no navegador ou use a extensão **Live Server** do VS Code.

## Requisitos

- Básico sobre internet
- HTML 5
- CSS 3

Cursos recomendados:
- https://plataforma.refatorando.com/cursos/internet/
- https://plataforma.refatorando.com/cursos/html-5-2/
- https://plataforma.refatorando.com/cursos/css-3/
